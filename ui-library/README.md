# Компоненты Каталога данных

Пакет `@data-catalog/ui` содержит React-компоненты Каталога данных и их стили. В Storybook работают эти же компоненты с синтетическими данными. Глобальный хедер и Навигатор принадлежат приложению.

Для локальной работы нужны Node.js 22.12+ и npm. Установите зависимости командой `npm ci`. Запустите `npm run storybook` для просмотра состояний, `npm run build:storybook` для статической сборки витрины и `npm run build` для сборки пакета. `npm pack` после сборки создаёт архив для установки в другом проекте.

```tsx
import { Accordion } from '@data-catalog/ui';
import '@data-catalog/ui/styles.css';

export function Example() {
  return <div className="catalog-ui">
    <Accordion title="Об отчёте">Описание отчёта</Accordion>
  </div>;
}
```

Пакет использует React 19, React DOM и React Router 7 из приложения. Для составных экранов, читающих маршрут, нужен провайдер роутера. Компоненты получают данные, обработчики и доступные действия через параметры. Шрифт задаётся переменной `--catalog-ui-font`. Каталог данных загружает свой шрифт на стороне приложения.

У контейнера `SourceLineageGraph` должна быть задана высота. Пример использует 480 px, а в паспорте источника граф занимает место, выделенное вкладкой.

Для новых проектов используйте публичные экспорты из `src/index.ts` и `@data-catalog/ui/styles.css`. Текущий прототип использует также пути `@data-catalog/ui/source/...` для совместимости со своей сборкой. Storybook публикуется отдельно из `storybook-static`.

## Темы

Без настройки компоненты используют светлые значения. Для единой темы приложения задайте `data-catalog-theme="dark"` или `data-catalog-theme="light"` на элементе `html`, чтобы настройки унаследовали компоненты и их меню и диалоги. Кнопка и хранение выбора принадлежат приложению. В Storybook темы доступны в меню «Тема». [Пилот Каталога данных](../README.md#тёмная-тема).
