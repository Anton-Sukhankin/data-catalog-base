# Каталог данных

Заготовка проекта корпоративного каталога данных. Будущий интерфейс на React предназначен для поиска и просмотра отчётов, метрик и источников данных.

## Состояние

Подготовлена только начальная структура репозитория. Исходники приложения, зависимости, сборка и тесты ещё не созданы.

Спецификации интерфейсов хранятся в [отдельном репозитории документации](https://github.com/Anton-Sukhankin/-.). Копировать их целиком в этот репозиторий не требуется.

## Состав

- [README.md](README.md) — назначение и текущее состояние проекта.
- [AGENTS.md](AGENTS.md) — инструкции для работы агентов.
- [.gitignore](.gitignore) — исключения для зависимостей, результатов сборки и локальных настроек.

## Следующий этап

Создать React-приложение по согласованной документации. Структура исходников, инструмент сборки и команды запуска и проверки будут определены при начале реализации.
