# Каталог данных

React-прототип корпоративного каталога. Основной интерфейс доступен по адресу /preview/navigation. В нём представлены «Главная», «Отчёты», «Метрики и показатели», «Источники», «Бизнес-словарь», AI Hub, «Справочники ИС» и «Вопросы и ответы». Экраны работают с демонстрационными данными. Подключение серверных операций, прав и хранения требует отдельной интеграции.

## Локальный запуск

Используйте Node.js 22 и npm 10. Проверенные версии — Node.js 22.19.0 и npm 10.9.3.

    npm ci
    npm run dev

Откройте http://127.0.0.1:5173/preview/navigation. Если порт занят, Vite выведет фактический адрес. Служебные страницы отдельных компонентов находятся в /previews/.

## Проверки

    npm run check
    npx playwright install chromium
    npm run test:e2e
    npm run test:e2e:production

Команда check проверяет типы, запускает модульные тесты и собирает приложение. Браузерные тесты запускают собственный сервер.

Для проверки имитации HTTP в режиме разработки скопируйте .env.example в .env.local и задайте VITE_DEMO_HTTP=true. По умолчанию приложение читает демоданные из памяти.

## Структура

- src/app — оболочка и маршруты.
- src/components и src/features — общие компоненты и экраны.
- src/data и src/demo — модели, правила выборки и демонстрационные данные.
- public и previews — ресурсы приложения и служебные страницы.
- tests — браузерные сценарии.

Для изменений интерфейса начните с [инструкций для агентов](AGENTS.md) и [оглавления спецификаций](https://github.com/Anton-Sukhankin/Data-Catalog-Context/blob/main/README.md).
