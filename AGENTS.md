# Каталог данных — инструкции для агентов

- Команды установки, запуска и проверки выполняются из корня репозитория. Начните с [README](README.md).
- Для изменения интерфейса откройте контракт нужного экрана, его компоненты и эталоны в [репозитории спецификаций](https://github.com/Anton-Sukhankin/Data-Catalog-Context/blob/main/README.md). Переиспользуйте общие компоненты и соблюдайте согласованное поведение.
- Сверяйте готовый экран с эталоном в том же состоянии, на тех же данных и при той же ширине окна. Проверьте затронутые переходы, фокус и обработку ошибок.
- Демоданные находятся в src/demo. Отделяйте локальное поведение интерфейса от серверных операций, прав и постоянного хранения.
- Выполняйте npm run check и применимые браузерные тесты. При изменении документированного поведения укажите затронутые спецификации.
- Храните в Git исходники, ресурсы и тесты. Зависимости, результаты сборки, локальные настройки и отчёты тестов создаются при запуске.
