# Каталог данных — инструкции для агентов

## Назначение и состояние

Репозиторий предназначен для будущего React-интерфейса системы «Каталог данных». Сейчас здесь только заготовка; приложения, установленных зависимостей и команд сборки или тестирования нет. Начать с [README.md](README.md).

## Источники и границы

- Выполнять текущую задачу пользователя в её согласованном объёме.
- Для реализации использовать относящиеся к задаче спецификации из репозитория документации, указанного в README. Подключать только нужные контракты, состояния и ресурсы.
- Различать согласованное требование, демонстрационные данные и неизвестное. Не придумывать отсутствующие интерфейсы, API, права или поведение.
- Этот репозиторий больше не предназначен для разработки дизайн-системы Rovna UI. Его прежняя история не задаёт архитектуру, зависимости или команды нового проекта.
- React согласован как основа интерфейса. Остальные инструменты выбирать при порученной инициализации проекта; не считать их уже установленными.
- Сохранять изменения пользователя и оставаться в пределах этого репозитория. Не изменять соседние проекты, репозиторий документации или макеты без соответствующего поручения.

## Изменения и проверки

- Переиспользовать общие компоненты и согласованные визуальные правила.
- Не сохранять в Git зависимости, сборки, кэши и секреты.
- После добавления приложения описать в README фактические команды установки, запуска, сборки и проверки.
- Выполнять проверки, соответствующие изменению. До появления приложения проверять состав файлов и ссылки; не объявлять сборку или тесты пройденными.
- При изменении документированного поведения определить затронутые спецификации и указать, какие требуют обновления; не дублировать их в этом репозитории.
- В результате отдельно указывать выполненные изменения, фактически пройденные проверки и оставшиеся ограничения.
